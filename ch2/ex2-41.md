# Exercise 2.41

*Context from the text:* for a run of ones in the constant K from bit position n down to bit position m (n ≥ m), the effect of these bits on `x * K` can be computed with either of two forms:

- Form A: `(x<<n) + (x<<(n-1)) + ... + (x<<m)`
- Form B: `(x<<(n+1)) - (x<<m)`

For a run of ones starting at bit position n down to bit position m (n ≥ m), we saw that we can generate two forms of code, A and B. How should the compiler decide which form to use?
