# Exercise 3.44

For each of the following structure declarations, determine the offset of every field, the total size of the structure, and its alignment requirement for x86-64:

```c
struct P1 {
    int i;
    char c;
    int j;
    char d;
};

struct P2 {
    int i;
    char c;
    char d;
    long j;
};

struct P3 {
    short w[3];
    char c[3];
};

struct P4 {
    short w[5];
    char *c[3];
};

struct P5 {
    struct P3 a[2];
    struct P2 t;
};
```
