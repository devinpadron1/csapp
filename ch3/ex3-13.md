# Exercise 3.13

The C code is:

```c
int comp(data_t a, data_t b)
{
    return a COMP b;
}
```

Here, `data_t` is one of the integer types in Figure 3.1, either signed or unsigned, and `COMP` is defined with `#define`. Suppose `a` is in a portion of `%rdx` and `b` is in a portion of `%rsi`. For each sequence, determine all possible `data_t` types and comparisons `COMP` that could produce it.

```asm
cmpl %esi, %edi
setl  %al

cmpw %si, %di
setge %al

cmpb %sil, %dil
setbe %al

cmpq %rsi, %rdi
setne %al
```
