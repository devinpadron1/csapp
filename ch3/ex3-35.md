# Exercise 3.35

For a C function with the following structure, fill in the missing expressions:

```c
long rfun(unsigned long x)
{
    if (/* TODO */)
        return /* TODO */;
    unsigned long nx = /* TODO */;
    long rv = rfun(nx);
    return /* TODO */;
}
```

```asm
# x in %rdi
rfun:
    pushq %rbx
    movq  %rdi, %rbx
    movl  $0, %eax
    testq %rdi, %rdi
    je    .L2
    shrq  $2, %rdi
```
