# Exercise 3.30

In the following C function, the body of the `switch` is omitted:

```c
void switch2(long x, long *dest)
{
    long val = 0;
    switch (x) {
        /* Body of switch omitted. */
    }
    *dest = val;
}
```

gcc generates this initial code, with `x` in `%rdi`:

```asm
switch2:
    addq $1, %rdi
    cmpq $8, %rdi
    ja   .L2
    jmp  *.L4(,%rdi,8)
```

The jump table is:

```asm
.L4:
    .quad .L9
    .quad .L5
    .quad .L6
    .quad .L7
    .quad .L2
    .quad .L7
    .quad .L8
    .quad .L2
    .quad .L5
```

1. What were the values of the case labels?
2. Which cases had multiple labels?
