# Exercise 3.33

A C function `procprob` has four arguments `u`, `a`, `v`, and `b`. Each is either a signed number or a pointer to a signed number, where the numbers have different sizes. The function has the following body:

```c
*u += a;
*v += b;
return sizeof(a) + sizeof(b);
```

It compiles to the following x86-64 code:

```asm
procprob:
    movslq %edi, %rdi
    addq   %rdi, (%rdx)
    addb   %sil, (%rcx)
```

Determine a valid ordering and types for the four parameters. There are two correct answers.

For comparison, another function is:

```c
void proc(long a1, long *a1p, int a2, int *a2p,
          short a3, short *a3p, char a4, char *a4p)
{
    *a1p += a1;
    *a2p += a2;
    *a3p += a3;
    *a4p += a4;
}
```

Its arguments are passed as follows:

- `a1` in `%rdi` (64 bits)
- `a1p` in `%rsi` (64 bits)
- `a2` in `%edx` (32 bits)
- `a2p` in `%rcx` (64 bits)
- `a3` in `%r8w` (16 bits)
- `a3p` in `%r9` (64 bits)
- `a4` at `%rsp+8` (8 bits)
- `a4p` at `%rsp+16` (64 bits)

```asm
proc:
    movq 16(%rsp), %rax  # Fetch a4p (64 bits)
    addq %rdi, (%rsi)    # *a1p += a1 (64 bits)
    addl %edx, (%rcx)    # *a2p += a2 (32 bits)
    addw %r8w, (%r9)     # *a3p += a3 (16 bits)
    movl 8(%rsp), %edx   # Fetch a4 (8 bits)
    addb %dl, (%rax)     # *a4p += a4 (8 bits)
    ret
```
