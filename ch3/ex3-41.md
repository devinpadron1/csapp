```c

        int x;
        int y;

    struct prob *next;
};
```

```c
void sp_init(struct prob *sp)
{
    sp->s.x = /* TODO */;
    sp->p = /* TODO */;
    sp->next = /* TODO */;
}
```

Determine the byte offsets of `p`, `s.x`, `s.y`, and `next`, and the total structure size.

The compiler generates:

```asm
# sp in %rdi
sp_init:
    movl 12(%rdi), %eax

    leaq 8(%rdi), %rax
```
