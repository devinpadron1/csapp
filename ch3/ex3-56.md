# Exercise 3.56

Consider the following C function, where EXPR is a macro defined with #define:

~~~c
double simplefun(double x) {
    return EXPR(x);
}
~~~

Below are three AVX2 code sequences generated for different definitions of EXPR, where x is held in %xmm0. All correspond to useful operations on floating-point values. Identify the operations. Your answers require understanding the bit patterns of the constant words retrieved from memory.

Sequence 1:

~~~asm
    vmovsd .LC1(%rip), %xmm1
    vandpd %xmm1, %xmm0, %xmm0
.LC1:
    .long 4294967295
    .long 2147483647
    .long 0
    .long 0
~~~

Sequence 2:

~~~asm
    vxorpd %xmm0, %xmm0, %xmm0
~~~

Sequence 3:

~~~asm
    vmovsd .LC2(%rip), %xmm1
    vxorpd %xmm1, %xmm0, %xmm0
.LC2:
    .long 0
    .long -2147483648
    .long 0
    .long 0
~~~
