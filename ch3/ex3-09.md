# Exercise 3.9

Suppose we want to generate assembly code for the following C function:

```c
long shift_left4_rightn(long x, long n)
{
    x <<= 4;
    x >>= n;
    return x;
}
```

Two instructions are omitted from this assembly. Parameters `x` and `n` are stored in `%rdi` and `%rsi`, respectively:

```asm
# x in %rdi, n in %rsi
shift_left4_rightn:
    movq %rdi, %rax       # Get x
    # TODO: x <<= 4
    movl %esi, %ecx       # Get n (4 bytes)
    # TODO: x >>= n
```

Fill in the missing instructions. The right shift should be performed arithmetically.
