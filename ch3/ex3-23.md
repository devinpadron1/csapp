# Exercise 3.23

For the following C code:

```c
long dw_loop(long x)
{
    long y = x * x;
    long *p = &x;
    long n = 2 * x;
    do {
        x += y;
        (*p)++;
        n--;
    } while (n > 0);
    return x;
}
```

gcc generates:

```asm
# x initially in %rdi
dw_loop:
    movq  %rdi, %rax
    movq  %rdi, %rcx
    imulq %rdi, %rcx
    leaq  (%rdi,%rdi), %rdx
.L2:
    leaq  1(%rcx,%rax), %rax
    subq  $1, %rdx
    testq %rdx, %rdx
    jg    .L2
    rep; ret
```

Identify the registers holding `x`, `y`, and `n`. Explain how the compiler eliminated `p` and the pointer dereference in `(*p)++`. Add annotations describing the operation, similar to Figure 3.19(c).
