# Exercise 3.14

The C code is:

```c
int test(data_t a)
{
    return a TEST 0;
}
```

For each sequence below, determine all possible `data_t` types and comparisons `TEST`. The argument `a` is held in a portion of `%rdi`.

1. ```asm
   testq %rdi, %rdi
   setge %al
   ```
2. ```asm
   testw %di, %di
   sete %al
   ```
3. ```asm
   testb %dil, %dil
   seta %al
   ```
4. ```asm
   testl %edi, %edi
   setle %al
   ```
