# Exercise 3.20

In the following C function, the definition of `OP` is incomplete:

```c
#define OP /* TODO: unknown operator */

long arith(long x)
{
    return x OP 8;
}
```

gcc generates:

```asm
# x in %rdi
arith:
    leaq  7(%rdi), %rax
    testq %rdi, %rdi
    cmovns %rdi, %rax
    sarq  $3, %rax
    ret
```

Determine `OP` and annotate the assembly to explain how it works.
