# Exercise 3.11

It is common to find assembly-code lines of the form `xorq %rdx,%rdx` in code that was generated from C where no exclusive-or operations were present.

1. Explain the effect of this particular exclusive-or instruction and what useful operation it implements.
2. What would be the more straightforward way to express this operation in assembly code?
3. Compare the number of bytes needed to encode these two different implementations of the same operation.
